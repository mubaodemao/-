# ✈️ 今天起飞不起飞

一个手机友好的小网页（H5 + PWA）：**随机决定今天的档位**（大飞特飞 / 起飞 / 小飞一下 / 不起飞），加上**今日不起飞打卡、联动日历、起飞时间计时**。
可以添加到手机主屏幕，像 APP 一样用，断网也能打开。

---

## 功能一览

### 🎡 每日起飞（首页 `index.html`）
- **四档结果**：🚀 大飞特飞 / ✈️ 起飞 / 🪁 小飞一下 / 🛋️ 不起飞，每次抽取带梗语、彩带、音效和轻微震动。
- **随机倍率**：起飞档位显示 **×N次（1~10）**；不起飞不显示。
- **按钮版 / 轮盘版**：点"转一下"或点轮盘中间「开始」；轮盘 8 格四档各 2，**先快后慢真实减速** + 旋转震动感。
- **⏱️ 起飞时间**：开始/结束计时，统计起飞次数、总时长、平均、最长 + 最近 5 条记录。
- **📊 出现次数**：四档各出现几次 + 进度条；结果卡显示累计次数。
- **📅 我的日历**：起飞日绿、不起飞日红（💤 优先），抽取/打卡后实时更新。
- **💤 起飞勋章**：按连续起飞天数解锁小飞侠/飞天达人/起飞之神/传奇机长。
- **今日已选择「今日不起飞」→ 第一页自动锁定**（抽取、轮盘、计时全部禁用）。

### 💤 今日不起飞（页面 `checkin.html`）
- 点「今日不起飞」记录今天，带鼓励语 + 音效震动。
- 统计本周/连续不起飞天数；🏅 勋章：定力新秀/意志达人/不动如山/坐怀不乱。
- **里程碑庆祝**：连续达 3/7/14/30 天首次解锁时，全屏彩带 + 大勋章 + 庆祝音效。
- 📅 日历与首页联动。

### 📈 数据报告（页面 `report.html`）
- 本周 / 本月切换：起飞天数、今日不起飞天数、计时次数、总/平均/最长时长、四档出现天数、一句话总结。

### ⚙️ 设置（页面 `settings.html`）
- 背景亮度滑块、字体大小（小/中/大）、音效开关、震动开关。
- **数据备份**：导出 / 导入 JSON，换设备或清缓存前先备份。
- **🗑️ 清空打卡数据**：一键清空「今日不起飞」记录，连续天数归零重来。

> 所有数据保存在**本机浏览器**（localStorage），清缓存会丢失；设置页可导出备份。

---

## 怎么在电脑上看

**方式一（推荐）**：双击 `index.html` 用浏览器打开。
**方式二**：本地服务器预览（PWA 安装/离线效果）：告诉我，我帮你起本地服务（`http://localhost:8899`）。

## 怎么在手机上看

- 先本地验收：把文件夹复制到手机，用手机浏览器打开 `index.html`。
- 正式上线：确认后部署到免费平台（Netlify），手机直接打开网址，还能"添加到主屏幕"当 APP 用。

## 项目文件

```
index.html / checkin.html / report.html / settings.html   四个页面
css/style.css       全部样式（霓虹渐变）
js/main.js          首页逻辑（四档随机、轮盘、计时、日历、勋章、锁定）
js/checkin.js       今日不起飞（打卡、勋章、庆祝动画）
js/report.js        周报/月报
js/settings.js      全局设置 + 数据备份/导入 + 背景/字体应用
js/sound.js         音效 + 震动（读取设置开关）
js/calendar.js      共享日历 + 记录数据（两页联动）
manifest.json / sw.js   PWA 配置 + 离线缓存
assets/             背景图、应用图标
```
