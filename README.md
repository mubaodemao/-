# 今天起飞不起飞 🛫 v3.0

一个轻松随缘的「今天飞不飞」小应用：按一下按钮或转一下轮盘，让命运替你决定今天的状态。

> 温馨提示：本应用仅面向已满 18 周岁的用户，请量力而行，健康第一。

## ✨ 功能

- 🎯 按钮版 / 🎡 轮盘版：一秒随机出今天的结果
- 🎲 概率分布：大飞特飞 10% ｜ 起飞 35% ｜ 小飞一下 20% ｜ 不起飞 35%
- 💬 超多骚话梗语：每档 8 句，每天不重样
- 📅 联动日历：起飞变绿、不起飞变红，一目了然
- 💤 今日不起飞打卡：连击攒勋章（定力新秀 → 意志达人 → 不动如山 → 坐怀不乱）
- ⏱️ 起飞计时：记录每一次时长与数据
- 🏅 成就勋章：连续坚持解锁专属称号
- 🎵 氛围电台：网页实时合成 BGM，可开可关可隐藏，抽完自动播报同款文案
- 📊 周报/月报：数据一目了然
- 💾 数据备份：导出/导入，换机不怕丢
- 📱 PWA：支持「添加到主屏幕」，离线也能用

## 🚀 使用

- 网页版：部署到任意静态托管（Netlify / GitHub Pages / Vercel 等）即可，纯前端零依赖。
- 手机版：浏览器打开后选择「添加到主屏幕」，即变成 App，离线可用。
